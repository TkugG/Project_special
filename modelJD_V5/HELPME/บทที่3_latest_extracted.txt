บทที่ 3 
วิธีการดำเนินงาน 
 
 การดำเนินโครงงานระบบสนับสนุนการตัดสินใจในการแนะนำตำแหน่งงานและจับคู่ทักษะ
สายไอทีด้วยการเรียนรู้ของเครื่อง ( IT Job Recommendation and Skill Matching Decision 
Support System Using Machine Learning) ผู้จัดทำโครงงานได้ประยุกต์ใช้ระเบียบวิธีวิจัย
มาตรฐานสากล CRISP-DM (Cross-Industry Standard Process for Data Mining) เป็นกรอบ
แนวทางหลักในการดำเนินงาน โดยครอบคลุมกระบวนก ารตั้งแต่การวิเคราะห์บริบท การจัดการ
ข้อมูล การพัฒนาแบบจำลอง จนถึงการนำระบบไปประยุกต์ใช้งานจริง ซึ่งแบ่งออกเป็น 6 ขั้นตอน
หลัก ดังแสดงในภาพที่ 3.1 
 
ภาพที่ 3.1 วงจรการพัฒนาระบบแนะนำตำแหน่งงานตามระเบียบวิธี CRISP-DM 6 ขั้นตอน

3.1 การทำความเข้าใจบริบท (Business Understanding) 
ขั้นตอนนี้มุ่งเน้นการศึกษาและวิเคราะห์สภาพปัญหาในการเข้าสู่ตลาดแรงงานของ
นักศึกษาไอที เพื่อกำหนดเป้าหมายและข้อกำหนดของระบบสนับสนุนการตัดสินใจให้สอดรับกับ
ความเป็นจริง 
3.1.1 สภาพปัญหาของระบบการค้นหางานในปัจจุบัน 
จากการศึกษาพบว่า ข้อมูลประกาศรับสมัครงานด้านไอทีส่วนใหญ่มีลักษณะเป็น
ข้อความแบบกึ่งโครงสร้างและไร้โครงสร้าง ( Semi-structured and Unstructured Text) ซึ่งใช้
คำศัพท์แสดงคุณสมบัติที่มีความหลากหลาย มีคำพ้องความหมาย ( Synonyms) หรือใช้ชื่อตำแหน่ง
งานที่ไม่สอดคล้องกัน ขณะที่ระบบรับส มัครงานดั้งเดิมส่วนใหญ่ยังคงพึ่งพาการสืบค้นด้วยคำสำคัญ
ตรงตัว ( Keyword Matching) ส่งผลให้ขาดความยืดหยุ่นในการทำความเข้าใจบริบทเชิงทักษะ ไม่
สามารถเชื่อมโยงทักษะที่นักศึกษามีเข้ากับกลุ่มอาชีพเป้าหมายของหลักสูตรได้อย่างเป็นรูปธรรม และ
ที่สำคัญที่สุดคือ ขาดกลไกก ารวิเคราะห์ช่องว่างทางทักษะ ( Skill Gap Analysis) ทำให้นักศึกษาไม่
ทราบว่าตนเองยังขาดทักษะจำเป็นด้านใดบ้าง จึงขาดข้อมูลเชิงลึกในการวางแผนพัฒนาตนเองก่อน
เข้าสู่ตลาดแรงงาน 
3.1.2 การกำหนดเป้าหมายของระบบสนับสนุนการตัดสินใจ 
เพื่อแก้ไขปัญหาดังกล่าว โครงงานนี้จึงกำห นดเป้าหมายในการพัฒนาระบบ
สนับสนุนการตัดสินใจที่มีความโปร่งใสและตรวจสอบได้ ( Explainable AI) โดยมีข้อกำหนดสำคัญ 3 
ประการ 
1. การจำแนกสายงานตามหลักสูตร ใช้กรอบ 8 กลุ่มอาชีพตามหลักสูตร
ของสาขาวิชาเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏนครปฐม เป็นแกนอ้างอิงกลางในการ
ประเมินความสอดคล้องของชุดทักษะ 
2. การแนะนำตำแหน่งงานจริง แนะนำตำแหน่งงานจากตลาดแรงงานไอที
ที่มีความเหมาะสมที่สุด 5 อันดับแรก โดยใช้กระบวนการจับคู่ตำแหน่งงานแบบสองขั้นตอน ( Two-
Stage Recommendation Pipeline) 
3. การชี้เป้าช่องว่างทักษะ แจกแจงทักษะที่มีตรงกันและทั กษะที่ยังขาดอยู่
ด้วยหลักการทางตรรกศาสตร์ เพื่อให้นักศึกษานำไปใช้วางแผนพัฒนาสมรรถนะวิชาชีพได้อย่างตรงจุด

3.2  การทำความเข้าใจข้อมูล (Data Understanding) 
ขั้นตอนนี้ครอบคลุมการกำหนดแหล่งข้อมูล การสุ่มตัวอย่าง การขจัดความกำกวม
ของข้อมูล และการจัดทำพจนานุกรมข้อมูล 
 3.2.1 แหล่งข้อมูลและเกณฑ์การคัดเลือกข้อมูล (Inclusion & Exclusion Criteria) 
แหล่งข้อมูลที่ใช้ในการดำเนินงาน รวบรวมจากประกาศรับสมัครงานด้านเทคโนโลยี
สารสนเทศบนเว็บไซต์รับสมัครงานชั้นนำในประเทศไทย (อาทิเช่น JobsDB Thailand, JobThai 
และแพลตฟอร์มหางานด้านไอทีที่เกี่ยวข้อง) ภายใต้เกณฑ์การคัดเลือกข้อมูลดังนี้ 
1. เกณฑ์การคัดเข้า (Inclusion Criteria) 
 - เป็นประกาศรับสมัครงานที่มีลักษณะงานตรงกับขอบเขต 8 กลุ่ม
อาชีพตามหลักสูตรของสาขาวิชา 
 - มีการระบุรายละเอียดทักษะความรู้ทางเทคนิค ( Technical 
Skills / Hard Skills) อย่างชัดเจนอย่างน้อย 3 ทักษะขึ้นไป 
 - เป็นประกาศรับสมัครงานที่มีสถานะเปิดรับสมัครจริงในประเทศ
ไทย ทั้งภาษาไทยและภาษาอังกฤษ 
2. เกณฑ์การคัดออก (Exclusion Criteria) 
 - ประกาศงานที่ระบุเฉพาะคุณสมบัติทั่วไป ( Soft Skills) โดยไม่มี
การระบุทักษะทางเทคนิค 
 - ประกาศงานที่มีความซ้ำซ้อนกันจากองค์กรและแผนกเดียวกัน 
(Duplicate Postings) 
3.2.2 ระเบียบวิธีการรวบรวมข้อมูลและขนาดตัวอย่างเป้าหมาย ( Sampling 
Protocol) 
การศึกษานี้ใช้ระเบียบวิ ธีการสุ่มตัวอย่างแบบเจาะจง ( Purposive Sampling) โดย
กำหนดขนาดตัวอย่างเป้าหมายกลุ่มละประมาณ 15–20 ตำแหน่งงาน ครอบคลุม 8 กลุ่มอาชีพตาม
หลักสูตรของสาขาวิชา รวมทั้งสิ้นประมาณ 120–160 ตำแหน่งงาน เพื่อให้การกระจายตัวของข้อมูลมี
ความสมดุลระหว่างกลุ่มอาชีพ ( Balanced Classes) และมีขนาดตัวอย่างที่เพียงพอต่อการทดสอบ
ความถูกต้องของแบบจำลอง

3.2.3 การขจัดความกำกวมและการรับรองความถูกต้องของข้อมูล ( Disambiguation 
& Verification) 
เนื่องจากประกาศรับสมัครงานในตลาดแรงงานมักมีการใช้ชื่อตำแหน่งงานที่
หลากหลาย เพื่อป้องกันความเอนเอีย งและข้อผิดพลาดในการกำหนดฉลากกลุ่มอาชีพ ( Labeler 
Bias) ระบบได้กำหนดแนวทางปฏิบัติดังนี้ 
1. การขจัดความกำกวม ( Disambiguation Protocol) ในกรณีที่ชื่อ
ตำแหน่งงานมีความคลุมเครือ ผู้จัดทำจะใช้ กรอบมาตรฐานอาชีพและคุณวุฒิวิชาชีพ สาขาวิชาชีพ
เทคโนโลยีสารสนเทศและการสื่ อสารและดิจิทัลคอนเทนต์ ของสถาบันคุณวุฒิวิชาชีพ (องค์การ
มหาชน) หรือ TPQI เป็นเกณฑ์อ้างอิงในการเทียบเคียงลักษณะงาน 
2. การรับรองความถูกต้องของชุดข้อมูล ( Ground Truth Verification) 
ข้อมูลตำแหน่งงานที่รวบรวมและกำหนดรหัสกลุ่มอาชีพทั้งหมด จะผ่านการตรวจสอบและรับรอ ง
ความถูกต้องโดยอาจารย์ที่ปรึกษาโครงงาน เพื่อยืนยันความเที่ยงตรงเชิงเนื้อหา ( Content Validity) 
ก่อนนำเข้าสู่กระบวนการเตรียมข้อมูล 
3.2.4 การจำแนกกลุ่มอาชีพและโครงสร้างพจนานุกรมข้อมูล ( Curriculum Career 
Taxonomy) 
ชุดข้อมูลตำแหน่งงานได้รับการจำแนกออกเป็น 8 กลุ่มอาชีพตามมาตรฐานหลักสูตร

3.3  การเตรียมข้อมูล (Data Preparation) 
ขั้นตอนนี้เป็นการแปลงข้อมูลข้อความดิบให้อยู่ในรูปเวกเตอร์ตัวเลขที่มีมาตรฐาน
และพร้อมสำหรับการประมวลผล 
3.3.1 การทำความสะอาดข้อมูลและการคุ้มครองคำศัพท์ทางเทคโนโลยี ( Data 
Cleaning & Protected Terms) 
เนื่องจากคำศัพท์ทักษะทางไอทีมักประกอบด้วยสัญลักษณ์พิเศษ เช่น C++, C#, 
.NET หรือ Node.js หากใช้การทำความสะอาดข้อความทั่วไป สัญลักษณ์เหล่านี้จะสูญหาย ระบบจึง
ออกแบบกลไกคุ้มครองคำศัพท์ 5 ขั้นตอน 
1. การแทนที่คำศัพท์เฉพาะด้วยคีย์เวิร์ดคุ้มครองชั่วคราว ดังแสดงในตาราง
ที่ 3.3 
2. การปรับข้อความเป็นตัวพิมพ์เล็กทั้งหมด 
3. การขจัดเครื่องหมายวรรคตอนที่ไม่จำเป็น 
4. การตัดแบ่งคำศัพท์ทักษะเดี่ยว 
5. การคืนรูปคีย์เวิร์ดคุ้มครองกลับสู่คำศัพท์มาตรฐาน 
 
ตารางที่ 3.3 ตัวอย่างคำศัพท์คุ้มครองทางเทคโนโลยี
