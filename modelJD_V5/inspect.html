  • คะแนนดิบ Logit (z_k): เกิดจากผลคูณเชิงเส้น w * x + b มีทั้งค่าบวกและติดลบได้ตามน้ำหนัก

Set Difference
โพยจุดตายสำคัญที่สุด: ตอบคำถามอาจารย์เรื่อง Set Theory: Vital Defense Answer
  • อาจารย์ถาม: "ทักษะที่มีกับขาด ไม่ได้ออกมาจากโมเดลเหรอ ทำไมต้องใช้ทฤษฎีเซต?"
