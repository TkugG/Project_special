# แผนการทดลอง: เชื่อมต่อตำแหน่งงานไอทีไทยและจำแนกเข้าสู่ 8 อาชีพตามหลักสูตร มคอ.2

แผนนี้จัดทำขึ้นเพื่อทดลองสร้างโมดูลดึงข้อมูลตำแหน่งงานไอทีจริงในประเทศไทย (Blognone Jobs Open Feed) และจัดหมวดหมู่เข้าสู่ 8 สายงานตามกรอบมาตรฐานหลักสูตร มคอ.2 ของสาขา IT โดยยังไม่กระทบกับระบบหลักเดิม

---

## 🎯 8 อาชีพตามกรอบหลักสูตร มคอ.2 สาขา IT

1. **8.1 เจ้าหน้าที่คอมพิวเตอร์ (Computer Officer / IT Support)**
2. **8.2 ผู้ดูแลระบบเครือข่ายคอมพิวเตอร์ (Network Administrator / Engineer)**
3. **8.3 นักพัฒนาและออกแบบสื่อผสม (Multimedia Designer & Developer)**
4. **8.4 นักจัดการโครงการสารสนเทศ (IT Project Manager / Coordinator)**
5. **8.5 นักวิเคราะห์และออกแบบระบบงาน (System Analyst / Business Analyst)**
6. **8.6 นักพัฒนาซอฟต์แวร์ (Software Developer / Software Engineer)**
7. **8.7 นักออกแบบและพัฒนาเว็บไซต์ (Web Designer & Developer)**
8. **8.8 อื่นๆ / ผู้เชี่ยวชาญเฉพาะทาง (Specialist / Emerging IT Roles)**

## 📋 ขั้นตอนการทดลอง (Experimentation Phases)

### ระยะที่ 1: สร้างสคริปต์ทดสอบการดึงข้อมูลและสกัดทักษะ (Standalone Prototype)
สร้างไฟล์ทดลอง [`src/fetch_thai_jobs.py`](file:///C:/Users/ASUS/Documents/modelJD/src/fetch_thai_jobs.py) ซึ่งมีหน้าที่:
- ดึงประกาศรับสมัครงานจริงในไทยผ่าน Blognone Public RSS/Atom Feed
- ใช้ **คลังคำศัพท์ทักษะมาตรฐาน 1,600+ คำเดิม** (`UNIQUE_SKILLS_LIST`) สแกนจับทักษะเทคนิค (Skill Extraction)
- จำแนก (Mapping) ตำแหน่งงานเข้าสู่ **8 อาชีพตาม มคอ.2** ด้วย Rule-based Classifier
- ตรวจจับระดับประสบการณ์ (Junior/Fresher 0-1 ปี vs Experienced 3+ ปี)

### ระยะที่ 2: รันและตรวจสอบผลลัพธ์บน Terminal
- ทดสอบรัน `python src/fetch_thai_jobs.py`
- ตรวจสอบความถูกต้องของการจัดหมวดหมู่ 8 อาชีพ และความแม่นยำในการดึงทักษะ

### ระยะที่ 3: สรุปผลและเตรียมเชื่อมต่อเข้ากับระบบหลัก
- หากผลการทดลองแม่นยำ สามารถบันทึกผลลัพธ์รวมเข้าสู่ฐานข้อมูล `data/job_dataset.csv` และปรับหน้าเว็บ UI ให้เลือกเฉพาะ 8 อาชีพนี้ได้ทันที
